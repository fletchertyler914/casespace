# Competitive Position — CFE Report Workspace

**Last updated:** 2026-05-22  
**Related:** [pmf-thesis-cfe.md](pmf-thesis-cfe.md)

## Positioning statement

CaseSpace occupies the **empty intersection** of: local-first + CFE-specific + citation-backed + standards-conformant report generation. Cloud eDiscovery and litigation-chronology tools serve different buyers at different price points.

## Why CaseSpace wins solo CFEs

1. **Privacy** — No cloud upload; engagement letters often prohibit SaaS evidence stores.
2. **Price** — Pro tier below CaseFleet Advanced AI ($75/mo); perpetual license option.
3. **Deliverable focus** — Built for examination report + expert witness, not generic chronology or eDiscovery review.
4. **Defensibility** — Standards footer + citation pills map to ACFE / FRCP / SSFS requirements counsel asks about.

## Why we lose (honest)

- **Large firm eDiscovery** — Everlaw / Relativity win on volume, TAR, and matter scale.
- **Litigation chronology-only** — CaseFleet wins if buyer only needs timeline + citations in cloud.
- **Bank statement forensics** — DocuClipper wins on PDF bank extraction depth.
